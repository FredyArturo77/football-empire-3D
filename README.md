*IMPERIO DEL FÚTBOL 3D* es un simulador de fútbol 3D multiplataforma y 100% open source desarrollado en Unity URP. Proyecto creado para que desarrolladores indie de LATAM puedan crear su propio juego de fútbol sin depender de licencias de EA/Konami.

## 🎯 Objetivo del Proyecto

Crear un juego de fútbol 3D completo con:
- *Modo Gestión*: Fichajes, economía, crear club
- *Gameplay 3D*: Partidos 11 vs 11 con IA
- *Generación Procedural*: 2000 jugadores, 200 países, 40 ligas ficticias
- *Optimizado para Móvil*: 60 FPS en gama media
- *Modo Dios Admin*: Solo para desarrollo y testing

## 🚀 Características Principales

- [x] Arquitectura base en Unity 2022.3 LTS
- [x] Sistema de economía: Monedas y Diamantes
- [x] Generador de jugadores y clubes procedural
- [x] Sistema de ligas con ascensos y descensos
- [x] Editor de jugador "Super Dotado"
- [ ] IA de partidos
- [ ] Modo Carrera completo
- [ ] Multijugador online

## 🛠️ Tecnologías

- *Motor*: Unity 2022.3 LTS + URP
- *Lenguaje*: C#
- *Plataformas*: Android, iOS, Windows, Mac
- *Sistema de Control*: Input System + Joystick móvil
